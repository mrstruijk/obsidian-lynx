# Plan: Show color preview next to color settings

## Goal
In the Lynx plugin settings, each color dropdown currently only shows labels like `Link`, `Accent`, `Normal`, etc. The user cannot tell which actual color these labels resolve to. Add a small color swatch next to each color dropdown that displays the currently selected color using the CSS variable it represents.

## Design choice
Native Obsidian `DropdownComponent` is a standard HTML `<select>`, and styling individual `<option>` elements with colors is unreliable across browsers. We will therefore add a persistent color preview **swatch** next to each color dropdown instead. When the user picks a different option, the swatch updates instantly to show the resolved color.

This is the approach the user selected.

## Files to change
1. `src/settings.ts` — add color preview swatch next to each color dropdown.
2. `styles.css` — add `.lynx-color-preview` styles.

## Detailed steps

### 1. `src/settings.ts`
- Extract the three color dropdown blocks (incoming `src/settings.ts:116`, outgoing `src/settings.ts:131`, bidirectional `src/settings.ts:176`) into a small helper function so the same dropdown + swatch logic is reused.
- The helper should:
  1. Create a `Setting` with the given name/description.
  2. Add the dropdown with options from `LYNX_CSS_COLORS`.
  3. Create a `div` swatch element.
  4. Append the swatch after `dropdown.selectEl` inside the same parent so it sits right next to the dropdown.
  5. Set the swatch `background-color` to the currently selected CSS variable value (e.g., `var(--link-color)`).
  6. On change, update the setting value, save it, and update the swatch `background-color` to the new variable.
- Keep labels and values unchanged (`LYNX_CSS_COLORS` stays the same).

### 2. `styles.css`
- Add a `.lynx-color-preview` class with:
  - width/height ~18px
  - rounded corners (`var(--radius-s)`)
  - border using `var(--background-modifier-border)` so it is visible on light/dark backgrounds
  - `margin-left` matching Obsidian setting control gaps
  - `flex-shrink: 0`
  - `background-color` set inline by the helper

## Verification
1. Run `npm run build` — must pass TypeScript and esbuild.
2. Run `npm run lint` — must pass ESLint with `eslint-plugin-obsidianmd` rules.
3. Manual test:
   - Build/copy `main.js`, `manifest.json`, `styles.css` to vault plugin folder.
   - Open Obsidian → Settings → Community plugins → Lynx.
   - Confirm each color setting (incoming, outgoing, bidirectional) shows a colored square next to its dropdown.
   - Change each dropdown and confirm the swatch updates to the new color.
   - Switch between light/dark themes and confirm swatches still reflect the resolved CSS variable.
