# Lynx note picker modal icons

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show incoming/outgoing direction icons in the "Pick linked note" modal, using the same user-configurable colors and icons as the Lynx sidebar panel.

**Architecture:** Reuse existing `LynxSettings` fields (`incomingIcon`, `outgoingIcon`, `incomingColor`, `outgoingColor`) and `LinkItem.type`. In `LynxNotePickerModal.renderSuggestion`, build each suggestion row as a flex container with an icon span (rendered via Obsidian `setIcon`) and a text column (display name + path). Color the icon by setting `--lynx-link-color` on the row and consuming it in CSS, identical to the sidebar approach.

**Tech stack:** TypeScript, Obsidian API, esbuild.

## Global constraints
- `minAppVersion` is `1.7.2` (`manifest.json:5`); only use APIs available at that floor.

**Interfaces:**

### Step-by-step

- [ ] **Step 1: Import `setIcon` from `obsidian`**

  In `src/note-picker-modal.ts`, change the import line to:

  ```ts
  import { App, setIcon, SuggestModal, TFile } from 'obsidian';
  ```

- [ ] **Step 2: Add CSS variable constant**

  Add at the top of `src/note-picker-modal.ts`:

  ```ts
  const LYNX_LINK_COLOR_VAR = '--lynx-link-color';
  ```

- [ ] **Step 3: Rewrite `renderSuggestion`**

  Replace the current `renderSuggestion` implementation with:

  ```ts
  renderSuggestion(item: LinkItem, el: HTMLElement): void {
  	el.addClass('lynx-suggestion');
  	el.style.setProperty(
  		LYNX_LINK_COLOR_VAR,
  		item.type === 'incoming'
  			? this.plugin.settings.incomingColor
  			: this.plugin.settings.outgoingColor,
  	);

  	const icon = el.createSpan({ cls: 'lynx-suggestion-icon' });
  	setIcon(
  		icon,
  		item.type === 'incoming'
  			? this.plugin.settings.incomingIcon
  			: this.plugin.settings.outgoingIcon,
  	);

  	const content = el.createDiv({ cls: 'lynx-suggestion-content' });
  	content.createDiv({
  		cls: 'lynx-suggestion-title',
  		text: item.displayName,
  	});
  	content.createDiv({
  		cls: 'suggestion-note',
  		text: item.path,
  	});
  }
  ```

- [ ] **Step 4: Add modal suggestion styles to `styles.css`**

- No new settings are required; existing icon/color settings are reused.
- The path subline keeps the Obsidian built-in `suggestion-note` class for consistent muted styling.
