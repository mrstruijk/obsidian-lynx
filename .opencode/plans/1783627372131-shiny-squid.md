# Custom Lynx sidebar tab icon — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the generic `link` sidebar-tab icon for the Lynx view with a custom lynx-head SVG derived from the existing `logo.png`.

**Architecture:** Convert `logo.png` into a small SVG path, register it as a custom Obsidian icon via `addIcon` in the plugin `onload`, and return its id from `LynxLinksView.getIcon()`. The bundled plugin will embed the SVG as a TypeScript string so the release artifacts remain self-contained.

**Tech Stack:** TypeScript, esbuild, Obsidian API (`addIcon`, `setIcon`), SVG path.

### Task 1: Convert `logo.png` to a compact SVG path

**Files:**
- Read: `logo.png` (1254×1254 PNG lynx head logo)
- Create: `src/lynx-icon.ts`

**Interfaces:**
- Consumes: none.
- Produces: `LYNX_ICON_SVG: string` and `LYNX_ICON_ID: 'lynx'` exported from `src/lynx-icon.ts`.

**Approach:** Use an external vectorisation/conversion step (Inkscape trace, SVGOMG, or hand-trace the logo) to produce an SVG with a single filled path fitting a 24×24 viewBox. The logo is a high-contrast black lynx head on white, so an autotrace should yield a clean path. Keep the final path string under ~2 KB gzipped; if the trace is too noisy, simplify with a tool like `https://yqnn.github.io/svg-path-editor/` or Illustrator simplify.

- [ ] **Step 1: Generate SVG**

Convert `logo.png` to SVG. Recommended command-line path:

```bash
# Using potrace (install via Homebrew: brew install potrace)
# Convert PNG to PNM first, then trace, then scale/crop to 24x24 viewBox.
pngtopnm logo.png > /tmp/logo.pnm
potrace -s -o /tmp/logo.svg /tmp/logo.pnm
```

Then edit `/tmp/logo.svg` to:
- Set `viewBox="0 0 24 24"`
- Center and scale the path to fit.
- Remove fills/strokes; the icon will inherit `currentColor` from Obsidian CSS.
- Keep only one or a few `<path d="..."/>` elements.

- [ ] **Step 2: Embed SVG in TypeScript**

Create `src/lynx-icon.ts`:

```ts
export const LYNX_ICON_ID = 'lynx';

export const LYNX_ICON_SVG = '<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor"><path d="..."/></svg>';
```

Replace `...` with the actual path data from Step 1.

- [ ] **Step 3: Verify visually**

Open the SVG in a browser or SVG viewer to confirm it reads as a lynx head at 24×24 px.
